# landing-page-for-gym
📌 Project Overview

HOUSE OF FITNESS is a modern and responsive gym landing page designed to showcase fitness services, pricing plans, and membership options. This project focuses on clean UI design, structured layout, and responsive styling using pure HTML and CSS.
The goal of this project is to demonstrate frontend development skills including layout design, flexbox usage, component structuring, and basic UI styling.
🚀 Features:
Hero section with motivational content
Pricing section with membership plans
Plan comparison table
Clean and structured layout
Custom utility CSS classes
Organized file structure
Tech Stack
HTML5
CSS
Flexbox
Google Fonts
